In order to run the simulation simply run the file "project.cc" in ns-3. File currently set at 18 stations,
should you wish to run on different amount either change in the code or use the flag nWifi in terminal and set
value there. 

To run the code: ./ns3 run ${path to project.cc}$ 

Alternatively could use: ./ns3 run ${path to project.cc}$ -- --"nWifi=x" where x is the amount of stations you want to run

If you don't want to edit project.cc directly.
During simulation the code itself was edited.
